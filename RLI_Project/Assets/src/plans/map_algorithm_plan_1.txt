[지형 분포]
perlin + 경로 가중치 = 동굴같은 던전
 - 변형: perlin + 경로 가중치 + 바이옴 가중치: 다양한 형태 구현 가능
 	- 단점: 바이옴 가중치 잡기 더럽게 빡셀듯

* 경로 가중치의 시작점은 Door 이다. Door 는 구조물의 일종이지만, 경로 선분만 보장하고, 문 구조물 자체는 평행이동 되어 길
	경로 선분 위에서 임의로 정한 점 위에 설치된다.
	(다른 구조물들은 평행이동 자체가 없음. )
* Structure 는 경로 가중치 설정과 함께 위치가 랜덤으로 결정되는데, Structure 의 경로 가중치는
대개 사전 정의되어있다. 
즉, 사전 정의된 경로 가중치를 잘 끼워 맞춰서 경로 가중치 맵을 얻어내야함
	* Structure 는 종류가 다양한데, 바이옴과 설치하기로 결정난 Structure등에 따라서
	조율되어 위치가 결정된다. 
	* 일반적으로 n*m 사이즈로 정의되며 이에 대한 경로 가중치도 n*m으로 같이 제공된다

* (perlin + 경로 가중치 + 바이옴 가중치) & 함정 + 몬스터 랜덤 배치 후, 
원래 Structure 가 있어야 할 곳에 Structure 을 배치함. 
	* 땅 등에 껴서 생성 불가능한 몬스터는 삭제됨
	* 함정은 개별 고유 규칙에 따라서 파괴될 수 있음
		규칙 확인은 TrapBase 추상 클래스에서 강제로 구현시킹
	* 함정, 몬스터들은 바이옴에 영향을 받아 결정됨
	* [지형 분포] 에 따른 타일 설치는 바이옴에 영향을 받음
